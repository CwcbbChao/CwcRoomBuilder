## 它是用来做什么的？

在制作地牢、肉鸽、RPG 或关卡游戏时，搭建室内房间常常面临三大繁琐痛点：
1. **拼砖枯燥费时**：关卡策划需要一块块手动摆地砖、立墙壁、转墙角、封天花板，改动一下房间尺寸就要把整个房间拆了重拼。
2. **家具陈设容易穿模穿帮**：手动摆桌椅太累，随机算法又经常把“书架嵌在墙壁里”、“两张桌子重叠穿模”、“椅子背对着房间面朝墙壁”。
3. **开门挖通道麻烦**：多个房间相互连通时，手动挖门洞极其容易漏墙缝或错位。

`CwcRoomBuilder` 就是为了解决这些痛点而生的 Unity 开源插件。你只需要在 Scene 视图里**像涂鸦画画一样用笔刷涂出房间形状**，系统就会自动帮你把**地板、墙面、天花板、门洞、靠墙书架、中央地毯、桌椅摆设**全自动搭建整齐，且**永远朝向正确、绝不穿模**。

## 核心功能与解决的痛点

### 1. 像涂鸦一样刷出房间（Scene 视图交互笔刷）
- 在编辑器的 Scene 视图中自带可视化网格画板。
- 支持**笔刷大小调节、矩形填充、一键清空、橡皮擦**等操作。
- 鼠标在网格上划过，就能自由画出任意形状的房间（L型房间、回廊、大殿、多房间连通）。

### 2. 结构件全自动拼接（地面、天花板、墙壁）
- 根据你画出的格子形状，系统自动分析内外边界：
  - 中间自动铺上**地板**与**天花板**；
  - 边缘自动竖起**直墙**；
  - 拐角处自动识别并旋转拼接**内拐角墙**与**外拐角墙**；
- 墙体与地砖完美契合，严丝合缝，彻底告别手动拼接对齐的折磨。

### 3. 门洞一插就通（DoorPin 门插销机制）
- 想在墙壁某处开门通向走廊？只需在对应位置放一个 `DoorPin` 组件。
- 系统在生成房间时会自动识别 DoorPin，**自动抹除该处的阻挡墙体，生成干净敞亮的门通道**，绝不漏缝漏风。

### 4. 聪明的家具与装饰品摆放（永远朝对方向，绝不穿模）
插件内建了空间距离场算法，家具能“看懂”自己离墙壁多远、朝向哪里：
- **靠墙家具（书架、火把、壁画、靠墙柜）**：自动吸附到墙边，严丝合缝推开摆好，并且**永远背靠墙壁、正面朝向房间内部**，绝不会面朝墙壁反向穿帮。
- **开阔地家具（大地毯、主雕像、大桌台）**：自动避开狭窄通道和角落，精准挑选房间最平坦开阔的腹地正中心。
- **墙角摆设（盆栽、落地钟、宝箱）**：自动识别 90 度墙角精准安放。
- **3D 防重叠碰撞保护**：桌子、椅子、箱子之间自带三维包围盒防护，多件家具绝不会叠在一起穿模。
- **桌上插槽（嵌套生成）**：支持在桌子上自动生成烛台或茶杯、在书架上自动生成卷轴等层级摆放。

### 5. 换一套预设，一秒切换整套美术风格
- 房间几何形状与美术预设彻底解耦。
- 同一个画好的房间形状，只要换一个 `RoomPreset` 资产，一秒就能从**阴森地牢**瞬间切换成**科幻太空舱**或**温馨小木屋**。

### 6. 一键换种子（Re-Roll Seed），抽卡式随机陈设
- 只要点一下 `Generate New Seed` 按钮，每次点击都能瞬间刷新出一套全新的家具陈设组合，便于策划快速挑选最满意的关卡布局。

## 安装方式

### 方式 A：通过 Unity Package Manager (推荐)
1. 打开 Unity 编辑器菜单栏：`Window` -> `Package Manager`。
2. 点击左上角 `+` 号 -> 选择 **Add package from git URL...**。
3. 填入仓库地址：
   ```text
   https://github.com/CwcbbChao/CwcRoomBuilder.git
   ```
4. 点击 **Add** 等待安装完成。

### 方式 B：直接复制代码
将 `CwcRoomBuilder` 文件夹直接复制到项目的 `Assets/` 或 `Packages/` 目录下即可。

## 极简使用步骤（三步搞定一个地牢房间）

### 第一步：创建房间生成器节点
1. 在场景 Hierarchy 中新建一个空 GameObject，命名为 `DungeonRoom`；
2. 为它添加组件：**`RoomBuilder`**；
3. 将配好的美术预设（例如 `Configs/NewRoomPreset.asset`）拖入 **Preset** 槽位；
4. 设置网格尺寸（例如画板宽度 `Canvas Width = 12`，高度 `Canvas Height = 12`，单个格子尺寸 `Tile Size = 3.0` 米）。

---

### 第二步：在 Scene 视图里画出房间形状
1. 选中该物体，在 Scene 视图中会看到一个地面网格画板；
2. 检视面板会弹出工具栏：
   - 点击 **Brush Mode: Draw Room**（绘制房间）；
   - 按住鼠标左键在网格上涂抹，画出房间的轮廓（如正方形大厅、长条走廊或十字大殿）；
   - 点击 **Box Fill** 还可以一键框选填充矩形区域。

---

### 第三步：点击生成！
1. 在 Inspector 面板点击底部的 **`Generate Room`** 按钮；
2. 房间的地面、天花板、墙壁以及桌椅家具瞬间全部生成完成！
3. 点击 **`Re-Roll Seed`** 可以随机换一套家具摆设；
4. 满意后无需额外操作，生成出的物体统一收纳在 `[Room_DungeonRoom]` 子节点下，结构清晰明了。

## 美术与策划预设说明

只需配置 ScriptableObject 资产，就能打造属于你的建筑库：

| 资产类型 | 用途说明 |
| :--- | :--- |
| **`RoomPreset`** | **房间综合美术预设**：统筹整个房间的美术风格，包含若干个“结构件组”和“装饰品组”。在 Project 视图右键 `Create -> Cwcbb -> Room Builder -> Room Preset` 即可创建。 |
| **`StructureGroup`** | **结构件库**：配置一组地板、天花板、直墙、内角墙和外角墙的预制体，支持配置随机抽取权重。 |
| **`DecorationGroup`** | **装饰品库**：配置家具（如桌椅、火把、地毯、宝箱），可以设置放置规则（靠墙 / 居中 / 墙角）、安全间距与出现概率。 |
